# War2.0

## Sobre o projeto

O **War2.0** é uma réplica digital inspirada no clássico jogo de tabuleiro **War**, desenvolvida para **PC** com foco em partidas **multiplayer**.

A proposta é transformar a experiência do jogo de tabuleiro em uma versão digital para computador, mantendo a essência de estratégia, conquista de territórios e disputa entre jogadores, enquanto adiciona recursos próprios de uma experiência multiplayer para PC.

## Objetivos iniciais

- Jogo para PC
- Multiplayer
- Sistema de territórios e conquista
- Estratégia baseada no estilo do War de tabuleiro
- Interface digital própria
- Estrutura preparada para evolução do projeto

> **Nota:** o projeto é uma recriação inspirada no conceito do jogo de tabuleiro e poderá desenvolver identidade, regras, arte e sistemas próprios ao longo do desenvolvimento.
